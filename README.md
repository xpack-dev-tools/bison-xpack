# The xPack GNU bison

A standalone, cross-platform (macOS, GNU/Linux) binary
distribution of GNU bison,
intended for reproducible builds.

## Project documentation

For information on how to install and use this project, please refer to the
[project website](https://xpack-dev-tools.github.io/bison-xpack/).

## Project source

The source code of the current release is available on
GitHub as [xpack-dev-tools/bison-xpack](https://github.com/xpack-dev-tools/bison-xpack),
the [v3.8.2-1.1](https://github.com/xpack-dev-tools/bison-xpack/tree/v3.8.2-1.1) tree.
